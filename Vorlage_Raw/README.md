# Fertige Bildvorlagen

Hier liegen freigegebene Bildvorlagen für das Spiel. Neue Bilder werden auf Nachfrage ergänzt.

## Karten – Version 2

[Karten und Layoutvorgaben öffnen](Karten_v2/LAYOUT_FUER_CLAUDE.md)

Sechs Hintergründe mit jeweils 780 × 1688 Pixeln und individuell gestalteten Brücken:

- [Raumstation](Karten_v2/space_dock.png)
- [Eiswelt](Karten_v2/ice_world.png)
- [Wüstenaußenposten](Karten_v2/desert_outpost.png)
- [Lava-Asteroid](Karten_v2/lava_asteroid.png)
- [Nebelportal](Karten_v2/nebula_portal.png)
- [Ringplanet](Karten_v2/ringed_planet.png)

Claude kann die PNGs direkt aus diesem Repository übernehmen. Gegner, Helden, Mauer und Benutzeroberfläche werden separat darübergelegt. Die ursprünglichen Spielressourcen werden durch diese Ablage noch nicht ersetzt.
